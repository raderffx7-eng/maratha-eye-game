# Maratha Eye Game

This is a simple offline battle royale-style browser game prototype inspired by Free Fire mechanics.

## Features

- Guest login screen
- Loading screen
- Main lobby
- Settings screen
- Profile and vault mockups
- Timer-based match preparation
- Plane drop flow
- Basic island map
- Loot pickups: medkit, ammo, gun
- Basic enemy bots and shooting

## Run locally

Open a terminal in this folder and run:

```bash
python -m http.server 8000
```

Then open in browser:

```text
http://localhost:8000
```

## Files

- `index.html` – game layout
- `style.css` – styling
- `script.js` – gameplay logic

## Notes

This is a playable prototype, not a full commercial 3D game. It gives the structure and gameplay flow you requested so you can extend it further.
